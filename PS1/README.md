# MilkyWayKeMazdoor — Mustafar Rocket Challenge

This directory contains the design files, simulation logs, flight visualisations, and final technical engineering report for team **MilkyWayKeMazdoor** in the OpenRocket Mustafar Rocket-Design Challenge.

---

## Directory Contents

| File | Type | Description |
| :--- | :--- | :--- |
| `MilkyWayKeMazdoor_Mustafar.ork` | OpenRocket Project | Complete two-stage rocket CAD and simulation setup file. |
| `MilkyWayKeMazdoor_Report.pdf` | Documentation | Final technical engineering report covering architecture, staging, recovery, and flight evaluation. |
| `Mustafar rocket plot.png` | Image / Plot | OpenRocket flight profile plot illustrating altitude, velocity, acceleration, and stage events over time. |
| `Mustafar sim info (sustainer).csv` | Telemetry Data | Time-series flight simulation telemetry export for the upper stage (sustainer). |
| `mustafar sim info (booster).csv` | Telemetry Data | Time-series flight simulation telemetry export for the lower stage (booster). |

---

## Instructions for Review

1. **CAD & Model Inspection:** Open `MilkyWayKeMazdoor_Mustafar.ork` in [OpenRocket](https://openrocket.info/) to inspect component dimensions, mass properties, fin geometry, and motor staging configurations.
2. **Telemetry Verification:** The CSV files can be inspected via any spreadsheet viewer or data analysis environment (e.g., Python/Pandas) to verify apogee, burnout velocity, and ground-impact dynamics.
3. **Engineering Assessment:** Consult `MilkyWayKeMazdoor_Report.pdf` for the full technical breakdown and verified performance audit.
